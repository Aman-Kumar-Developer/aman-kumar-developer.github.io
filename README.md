# Aman Kumar — Java Backend Developer Portfolio

A responsive, dark-themed personal portfolio website built to showcase my backend development projects, technical skills, and certifications. 

## 🚀 Overview

As a Computer Science Engineering graduate focused on Java backend development, I needed a central hub to display my work to recruiters and fellow developers. This portfolio highlights my expertise in **Core Java, Spring Boot, Hibernate/JPA, and MySQL**, along with my ongoing learning in cloud-native technologies like **Docker, Kubernetes, and AWS**.

## ✨ Features

* **Modern Dark Theme:** A sleek, custom-designed dark UI using CSS variables and modern layout techniques.
* **Fully Responsive:** Adapts seamlessly to desktop, tablet, and mobile screens using CSS Grid and Flexbox.
* **Interactive Lightbox:** Custom-built vanilla JavaScript image expansion modal for high-resolution profile picture viewing without sacrificing page load speed.
* **Scroll Animations:** Smooth reveal animations triggered by the Intersection Observer API.
* **Dynamic Navigation:** Sticky header with active state tracking based on scroll position.
* **Zero Frameworks:** Built entirely from scratch without heavy frontend libraries.

## 🛠️ Technologies Used

**Frontend (Portfolio Build):**
* HTML5
* CSS3 (Custom Variables, Grid, Flexbox, Media Queries)
* Vanilla JavaScript (ES6+)

**Backend (My Tech Stack Highlighted):**
* Java & Core OOP
* Spring Boot & Spring Data JPA
* Hibernate & JDBC
* RESTful APIs & Spring Security
* MySQL
* Docker, Kubernetes, AWS (Learning)

## 📂 Featured Projects

1. **Student Management System:** A Java application implementing CRUD operations and relational database interaction using JDBC and MySQL.
2. **Social Media Backend API:** A REST API built with Spring Boot utilizing layered architecture, user management, and authentication flows.
3. **Bookmark Cleaner:** A Java utility using Jackson to parse, validate, and clean browser bookmark JSON data while preserving folder structures.

## 💻 How to Run Locally

Since this is a static website, no build step or package installation is required:

1. Clone the repository:
   ```bash
   git clone https://github.com/aman-a25/aman-portfolio.git
   ```
2. Navigate to the project folder.
3. Open `index.html` in your preferred web browser.
